# Script Hub — Менеджер и лаунчер скриптов для Windows 11

**Script Hub** — современное нативное приложение для Windows 11 на базе **C# / .NET 8 / WPF**, использующее библиотеку **WPF-UI** (Fluent Design, слюда/Mica, светлая и темная темы) и редактор **AvalonEdit** для подсветки синтаксиса PowerShell и CMD/Batch.

**Автор**: Ларионов Никита (02.09.2026)

---

## 🚀 Основные возможности

1. **Современный интерфейс Windows 11**:
   - Fluent Design с эффектом Mica (слюда) на поддерживаемых версиях Windows 11.
   - Поддержка системной, светлой и темной тем оформления.
   - Шрифт Segoe UI Variable и системные акцентные цвета.
   - 3 режима масштабирования плиток: **Стандартный**, **Широкий**, **Компактный**.
   - Адаптивная сетка, плавная перестройка при изменении размера окна.

2. **Запуск скриптов**:
   - Поддержка PowerShell (`.ps1`) через `powershell.exe` или PowerShell 7 (`pwsh.exe`).
   - Поддержка Batch / CMD (`.bat`, `.cmd`) через `cmd.exe`.
   - Запуск от имени администратора с системным окном контроля учетных записей (UAC `runas`).
   - Гибкий выбор рабочей директории: папка скрипта, пользовательская папка, папка приложения или системная по умолчанию.
   - Передача аргументов запуска (например, `-Path "C:\Downloads" -Force`).
   - Встроенная консоль выполнения с потоковым выводом `stdout` / `stderr` в реальном времени, таймингами и кодами завершения.
   - Возможность остановить процесс в любой момент (завершение дерева процессов).

3. **Встроенный редактор**:
   - Редактор на базе AvalonEdit с подсветкой синтаксиса PowerShell и Batch.
   - Номера строк, моноширинный шрифт, поиск (`Ctrl+F`), сохранение (`Ctrl+S`), запуск (`F5`).

4. **Организация и поиск**:
   - Категории с цветовыми маркерами (Файлы, Сеть, Windows, 1С, Администрирование, Очистка, Резервное копирование, создание своих категорий).
   - Быстрый мгновенный поиск по названию, описанию, категории, пути и аргументам.
   - Избранное (закрепление звездочкой).
   - Сортировка по названию, типу, категории, дате последнего запуска.
   - Drag & Drop скриптов (`.ps1`, `.bat`, `.cmd`) прямо в окно приложения для мгновенного импорта.
   - Автоматическая проверка наличия файла на диске и предупреждение ⚠️ при его отсутствии.

5. **История и логирование**:
   - Полный журнал выполненных скриптов со статусами, кодами завершения и длительностью выполнения.
   - Возможность повторного запуска из истории в один клик.

6. **Резервное копирование**:
   - Экспорт всей конфигурации и скриптов в ZIP-архив.
   - Импорт конфигурации на любом другом компьютере.

7. **Встроенный пример**:
   - Автоматически инициализируемый PowerShell-скрипт **«Сортировка файлов по типам»**, демонстрирующий правильную работу с рабочей директорией.

## ⌨️ Горячие клавиши

| Сочетание клавиш | Действие |
|-------------------|----------|
| `Ctrl + N` | Создать новый скрипт |
| `Ctrl + O` | Импортировать скрипт |
| `Ctrl + F` | Фокус на поле поиска |
| `Ctrl + S` | Сохранить скрипт в редакторе |
| `F5` | Запустить выбранный скрипт / Сохранить и запустить из редактора |
| `Delete` | Удалить выбранный скрипт |
| `Ctrl + ,` | Открыть настройки |

## 🛠️ Сборка и запуск

### Вариант 1: Через Visual Studio 2022
1. Откройте файл `ScriptHub.sln` в **Visual Studio 2022** (с установленной рабочей нагрузкой *.NET Desktop Development*).
2. Нажмите **F5** для сборки и запуска в режиме отладки.

### Вариант 2: Через .NET CLI (Терминал)

Сборка проекта:
```powershell
dotnet build ScriptHub.sln
```

Запуск проекта:
```powershell
dotnet run --project ScriptHub/ScriptHub.csproj
```

Публикация в виде исполняемого файла (.exe):
```powershell
# Публикация Framework-dependent (требует .NET 8 на целевом ПК):
dotnet publish ScriptHub/ScriptHub.csproj -c Release -o ./publish

# Публикация автономного единого файла (Self-Contained Single-File, не требует установленного .NET):
dotnet publish ScriptHub/ScriptHub.csproj -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true /p:IncludeNativeLibrariesForSelfExtract=true -o ./publish-single
```

## 📁 Структура локального хранилища

Приложение сохраняет данные пользователя в `%LocalAppData%\ScriptHub\`:
```text
%LocalAppData%/ScriptHub/
 ├── Scripts/
 │    ├── PowerShell/
 │    │    └── Sort-FilesByType.ps1
 │    └── CMD/
 ├── Data/
 │    ├── scripts.json
 │    ├── categories.json
 │    └── appsettings.json
 ├── Logs/
 │    └── history.json
 └── Backups/
```
